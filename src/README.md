# Código-fonte

Módulos previstos:

- `load_data.py`: leitura de CSV.
- `validate_data.py`: validação de colunas e registros.
- `classify_with_ai.py`: chamada à API e interpretação da resposta.
- `schemas.py`: contratos e taxonomias.
- `export_data.py`: exportação CSV/JSON.
- `main.py`: orquestração do fluxo.

O código será implementado após estabilizar o schema de entrada e saída.
