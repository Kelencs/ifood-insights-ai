# Dados

O repositório deve conter apenas dados sintéticos ou anonimizados e autorizados.

- `sample_complaints.csv`: base sintética de entrada (a criar).
- `sample_enriched.csv`: exemplo de saída enriquecida (a criar).

Não publicar dados reais de clientes, restaurantes, entregadores ou pedidos. Não armazenar dados pessoais nesta pasta.
